# Architecture
User → Streamlit → Data Input → Validation → Deterministic Scoring → Ranking → What-if/Strategy Engine → Analytics → Gemini Explanation → Human Procurement Decision.

Enterprise evolution: CSV → SQL → cloud database/data warehouse → ERP/procurement APIs (e.g., SAP/Oracle/Dynamics/Coupa/Ariba), with authentication, RBAC, logging, monitoring, caching and AI usage controls.
